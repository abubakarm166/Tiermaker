# API reference

The full **HTTP API documentation** for mobile and web clients is maintained here:

- **Markdown (source):** [docs/API_REFERENCE.md](docs/API_REFERENCE.md)
- **Word / Google Docs:** [docs/API_REFERENCE.docx](docs/API_REFERENCE.docx) — upload this file to **Google Drive**, then open it and choose **Open with → Google Docs** to convert it to an editable Google Doc.

Regenerate the `.docx` after editing the markdown:

`python docs/build_api_reference_docx.py`
